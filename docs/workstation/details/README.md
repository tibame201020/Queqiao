# Workstation Detailed Info

**English** | [繁體中文](README.zh-TW.md) · [Workstation index](../README.md)

Press `i` while the Inspector owns focus to open Detailed Info as a root modal. The underlying Control/Inventory/Inspector panes remain mounted for context, but the modal owns input until `i` or `Esc` closes it.

Use `←` / `→` to change tabs and `↑` / `↓`, `PageUp`, `PageDown`, `Home`, `End` to scroll where needed.

Each domain has its own page with a final-frame screenshot, a real tab-navigation GIF, and the exact current tab contract:

- [Gateway](gateway.md) — Status / Info / Workers
- [Worker](worker.md) — Status / Info / Workspaces / Extensions / Gateways
- [Workspace](workspace.md) — Info / Access
- [Access Profile](access-profile.md) — Info / Tools / Commands
- [Extension](extension.md) — Info / Workers
- [Diagnostics](diagnostics.md) — Summary / Core / Routing / Extensions / Warnings

Detailed Info is read-oriented. Mutations remain in Inspector actions/forms so the modal does not become a second management surface.
